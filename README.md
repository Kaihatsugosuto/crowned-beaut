# Crowned Beaut

Projeto acadêmico da UNINOVE — 2026/2, sob orientação do professor Daniel Ferreira de Barros Junior.

A Crowned Beaut é uma vitrine digital de cosméticos que ajuda clientes a consultar produtos e preços e iniciar o atendimento pelo WhatsApp. O catálogo reúne itens de cuidados com a pele, lábios e cabelos em uma página adaptada para celulares e computadores.

## Links da entrega

- **Enunciado:** [Projeto 2026/2 — repositório do professor](https://github.com/DanielGTI/2026-2-projeto).

## Funcionalidades

- Catálogo com fotos, descrições e preços em reais.
- Filtros por categoria para facilitar a busca de produtos.
- Botões de WhatsApp com mensagem preenchida para o produto selecionado.

## Tecnologias e execução local

O site usa HTML, CSS e JavaScript. Para executar, baixe ou clone o repositório e abra o arquivo [`index.html`](index.html) no navegador. Não é preciso instalar dependências.

O [`style.css`](style.css) define o layout responsivo, o [`script.js`](script.js) renderiza o catálogo e aplica os filtros, e a pasta [`assets/`](assets/) reúne as imagens e os ícones.
